# Калькулятор поворота телевизора

Публичный сайт: https://mupamuc.github.io/tv-angle-planner/

Пять схем расположения телевизора, ограничения по геометрии комнаты, ручной ввод размеров корпуса и подбор диагонали по расстоянию до глаз. Расчёт не подтверждает прочность стены, крепежа или кронштейна.

## Запуск локально

Из каталога проекта:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/. Страница также работает при открытии `index.html` напрямую. Зависимости и сборка не нужны.

## Публикация

GitHub Pages публикует корень ветки `main`. Для обновления измените `index.html`, создайте коммит и выполните `git push`.
