# Калькулятор поворота телевизора

Публичный сайт: https://mupamuc.github.io/tv-angle-planner/

Пять схем расположения телевизора, ограничения по геометрии комнаты, ручной ввод размеров корпуса и подбор диагонали по расстоянию до глаз. Дополнительно: подбор высоты центра ТВ или настенного крепления с учётом смещения, направления взгляда и наклона экрана; объёмный вид комнаты с проверкой корпуса на пересечение со стенами и полом.

Профиль Philips 55OLED910 использует размеры без ножек 122,5 × 74 × 5,6 см из [официального паспорта](https://www.documents.philips.com/assets/20250411/a514563edbc340c2ab10b2bc01375d5c.pdf). Внешний вид ТВ и рычаг кронштейна условные. Смещение центра ТВ от настенной площадки вводится вручную; VESA не определяет его. Расчёт не подтверждает прочность стены, крепежа или кронштейна.

## Запуск локально

Из каталога проекта:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/. Для JavaScript-модулей используйте HTTP-сервер. Зависимости и сборка не нужны.

## Проверка геометрии

```powershell
node --test geometry.test.mjs
```

Проверяются формулы высоты, знаки смещения крепления, направление взгляда, наклон, пересечение всего корпуса со стенами/полом и ортографическая проекция.

## Публикация

GitHub Pages публикует корень ветки `main`. Для обновления измените `index.html`, создайте коммит и выполните `git push`.

Основой служит версия 4 исходного проекта Sites, коммит `cc44d7754e761fc8f6088e2c2d77ee83d9367894`. При переносе удалены служебный мост ChatGPT и неиспользуемые внешние библиотеки. Добавлены расчёт высоты, объёмная схема и ручной ввод глубины корпуса, связанный с расчётом зазоров.
